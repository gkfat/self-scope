## Why

「此刻／今日」這一類內容（每日塔羅、每日盧恩、今日瑪雅 Kin、即時星象）原本各自帶著首頁入口，這個 change 計畫把它們整併成一個首頁區塊、一個總覽頁與一個彙整 API。

**狀態：不實作。** 它的目標已經由「今日運勢」頁（`/fortune`）直接達成：塔羅、瑪雅 Kin、盧恩符文與星座運勢併在同一頁，首頁只有一個「今日運勢」區塊、側邊選單只有一個「今日運勢」項目。原本規劃的做法（`/today` 頁、`GET /api/today` 彙整端點、集中的項目清單）沒有採用，也暫時沒有必要。這份文件保留為紀錄，並列出日後若需要可以再做的收尾項目。

## What Changes

**不做任何程式或規格變更。** 原本規劃的內容與現況對照：

| 原本規劃 | 現況 |
|---|---|
| 首頁單一「此刻／今日」區塊，取代零散入口 | 已完成：首頁「今日運勢」區塊（`components/fortune/HomeEntry.vue`），各項各一行；訪客只看到說明與「立即登入」 |
| 側邊選單單一入口 | 已完成：單一「今日運勢」→ `/fortune` |
| 總覽頁 `/today` | 以 `/fortune` 取代：入口卡片並直接顯示今日結果，點擊後在同頁進入各項 |
| 舊入口移除（`/tarot`、`/rune`、`/kin`） | 已完成：改為轉址到 `/fortune#…` |
| 訪客不載入抽取結果 | 已完成 |
| 即時星象（付費 AI 報告） | 暫緩（`add-transit-report`）；第一步由免費的星座運勢取代 |
| `GET /api/today` 彙整端點 | **未做**；目前各項各自呼叫自己的 API |
| 集中的項目清單 `shared/constants/today.ts` | **未做**；項目與旗標在 `fortune.vue` 與 `HomeEntry.vue` 兩處 |
| 跨台北午夜重新查詢 | 各項面板已有；入口頁與首頁區塊**未做** |

**日後若要做的收尾項目**（皆非必要，等實際遇到問題再開新的 change）：

1. **彙整端點**：把首頁與今日運勢頁各項的請求（目前最多 4 次）合成 1 次，並讓單項失敗不影響其他項。
2. **集中的項目清單**：把旗標、圖示、文案收進單一設定，新增項目時不必同時改兩處。
3. **入口頁與首頁區塊跨午夜更新**：頁面重新取得焦點時重新查詢，日期以伺服器回應為準。
