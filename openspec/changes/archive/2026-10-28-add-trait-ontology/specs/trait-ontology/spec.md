## ADDED Requirements

### Requirement: 28 條兩極特質軸
系統 SHALL 定義 28 條特質軸，分為思考與認知、行動與節奏、情緒與表達、人際與關係、價值與動機五組。每條軸 MUST 有穩定的 ID 與恰好兩個端點；每個端點 MUST 有名稱、說明與「過度時的樣子」。軸與端點的 ID MUST 唯一，且一經發布 MUST NOT 重用。端點命名 MUST 為中性，不將一端描述為較好或較差。

#### Scenario: 結構完整
- **WHEN** 載入並驗證所有特質軸
- **THEN** 共 28 條，每條恰有兩個端點，每個端點的名稱、說明、過度說明皆非空

#### Scenario: ID 唯一
- **WHEN** 檢查所有軸與端點 ID
- **THEN** 沒有重複

#### Scenario: 缺端點被拒絕
- **WHEN** 某條軸只有一個端點
- **THEN** 驗證失敗並指出該軸

### Requirement: 情境軸
系統 SHALL 定義三組情境軸：時間（過去、現在、未來）、對象（自己、伴侶、家人、朋友、工作夥伴、群體，另含上司、下屬、孩子、陌生人）、生活領域（人際互動、自我成長、工作、娛樂、興趣發展、待人處事、決策與選擇、情緒與壓力、生活節奏、學習）。情境軸不是兩極，每個值有穩定 ID 與名稱。領域 MUST NOT 含「人際關係」（與對象軸重疊，改稱「人際互動」）。

#### Scenario: 三組情境值齊全
- **WHEN** 載入情境軸
- **THEN** 時間 3 個、對象 10 個、領域 10 個，ID 唯一

#### Scenario: 不含重疊的領域
- **WHEN** 檢查領域清單
- **THEN** 沒有「人際關係」，有「人際互動」

### Requirement: 本體版本
系統 SHALL 提供 `ONTOLOGY_VERSION` 字串，軸、端點或情境值的任何內容改動 MUST 同步提高該版本。

#### Scenario: 版本存在
- **WHEN** 讀取本體版本
- **THEN** 為非空字串
